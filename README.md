# NJ's Pro Tree Care LLC

A simple, responsive one-page website for NJ's Pro Tree Care LLC. It highlights 24/7 storm cleanup availability, tree trimming, and deadwood removal.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript and has no build tools or external dependencies.

## Before publishing

1. In `index.html`, set `BUSINESS_EMAIL` near the bottom of the file to the email address that should receive estimate requests. The quote form opens a prefilled message in the visitor's email app; it does not send or store information on its own.
2. Add the business phone number and any confirmed service-area details to the page if you'd like them shown. No contact number, email, or specific service area was supplied for this first draft, so none have been invented.
3. Review the service descriptions and availability details to make sure they accurately represent the business.

## GitHub Pages

In the repository's **Settings → Pages**, choose the `main` branch and `/ (root)` as the publishing source. The site files can also be merged from the `site-launch` branch first. GitHub Pages publishes the root `index.html` as the home page.
